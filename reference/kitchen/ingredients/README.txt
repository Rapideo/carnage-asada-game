TACO SHOP PIXEL-ART ASSETS

28 approved assets: 21 ingredient bins and 7 shell/bread assets.

originals/: Full-size transparent PNGs as generated.
sprites-45x46/: Nearest-neighbor reductions on exact 45 x 46 transparent canvases. These are downsampled versions, not independently hand-pixeled originals.
Both folders separate ingredient-bins from shells-and-bread.
preview.png: All 28 compact sprites enlarged 4x for browsing; the dark preview background is not included in the individual PNGs.
asset-list.csv: Names, original approval numbers, and paths.
prompts.txt: The final prompt used for each image.

Filenames retain the original approval-list numbers, so intentional gaps remain.
Excluded items: 20, 21, 22, 23, 25, 26, 27, 28, 29, 34, 35.

Style: 16-bit SNES/Genesis-inspired pixel art, 1970 American taco kitchen, stainless steel pans, slightly above frontal viewpoint, upper-left light. All assets were generated anew for this set because the earlier images were unavailable.
Pico/fresca is a visual interpretation using tomato, white onion, and green herb/chile pieces; the referenced menu did not define the exact fresca recipe.

Use nearest-neighbor scaling (or an image editor's pixel-art scaling option) when enlarging compact sprites to keep edges crisp.
