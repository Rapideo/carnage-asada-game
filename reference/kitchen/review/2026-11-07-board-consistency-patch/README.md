# Taco Shop prep-board consistency patch

Apply these 11 replacement PNGs to the full sprite set after the chili, beans, and sauce readability patch. Use the same paths under `states/`. The manifest is byte-identical.

The two finished chili dishes use the maroon chili from the approved build states. Chili Enchilada keeps its orange shredded cheddar. The beans-first chain uses the lighter beans from the approved beans-over-beef states, with a wider portion on the bare tortilla. All changed descendants are included.

The comparison sheets show the build and finish transitions before and after this patch with the game's 16-color reducer. The Bean Burrito cheddar remains a clearly separate orange layer. The source chili and refried-bean cutouts are the same ones included in the earlier readability patch.
