# Hays Map Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the randomly-zoned city with the real eight blocks of downtown Hays — real street names, real Hays addressing, and a hand-authored zoning table — with the Taco Shop on its real block.

**Architecture:** The map becomes authored JSON in `content/hays.json`, inlined at build time by `build.mjs` into the generated `src/05_content.js` as `const HAYS`, exactly as `winners.json` already becomes `const CONTENT`. `40_city.js` reads its street names and its block programme from that constant instead of from hard-coded arrays and a random roll. `classify()` is never touched, so the street grid itself does not move and the minimap cannot desync.

**Tech Stack:** Plain ES5-style browser JavaScript (no modules, no imports), Node 18+ for `build.mjs` and the test harness, zero runtime dependencies.

**Spec:** `docs/superpowers/specs/2026-08-21-hays-neighbourhood-design.md`

## Plan series

The spec covers three separable subsystems. This is the first of three; each ships working, playable software on its own.

1. **This plan — the map.** Street names, addressing, zoning table. The five new block kinds (`retail`, `civic`, `apts`, `church`, `auto`) and `rail` are accepted by the data and the validator, but render through existing generators via an explicit fallback table. Delivers: driving real Hays streets to real addresses.
2. **Plan 2 — the block kinds.** Replaces each fallback with a bespoke generator, plus the railway corridor as ground and geometry. One task per kind, each independently reviewable.
3. **Plan 3 — the Union Pacific.** The live train, crossing gates, the wreck, the cop interaction, and the traffic/demo changes.

## Global Constraints

Every task's requirements implicitly include this section. Values are copied verbatim from `CLAUDE.md` and the spec.

- **Zero dependencies.** No `package.json`, no `node_modules`, no imports, no CDN, no external asset files. Every sprite, the font, the city and all audio are generated procedurally at boot.
- **`src/*.js` are plain scripts, not ES modules.** No `import`/`export` anywhere. All modules share one global scope in the bundle, so a top-level `const` declared twice across two files is a fatal redeclaration that only surfaces in the bundle.
- **The numeric filename prefix is the load order and therefore the dependency order.** `05_content.js` loads before `40_city.js`, which is why `HAYS` is available to the city generator.
- **`src/05_content.js` is generated. Never edit it by hand.** Edit `content/*.json` and run `node build.mjs`.
- **`node build.mjs` must be run before `node test/headless.mjs`** whenever `content/*.json` changes. The harness reads `src/*.js` from disk, so a stale `05_content.js` means the tests run against old data — or throw `ReferenceError: HAYS is not defined`.
- **The 5×7 font is ASCII-only:** uppercase `A-Z`, `0-9`, space, and `` . , : ; ! ? $ + - / \ % # ( ) [ ] * = < > ' " _ & @ ^ ~ ``. Anything else fails the build by design. Watch for curly quotes from pasted text.
- **`BLOCKS` = 8, `SPAN` = 12, `TS` = 16, `BORDER` = 2** (`src/00_core.js`). Street-name arrays are `BLOCKS + 1` = 9 long.
- **The order card fits 135px of scale-1 text.** The card sits at x=3, is 140 wide, text is inset to x=8, with 3px pad. A scale-1 string is `len * 6 - 1` px.
- **`City.markSolid()` does not check `City.keep`.** Callers are responsible for testing `keep` before marking a tile solid, or they can bury a delivery porch and make an address unwinnable.
- **Do not touch `classify()` in `00_core.js`.** Six modules depend on its uniform-pitch assumption; the whole design avoids it.
- **Commit after every task.** Do not skip hooks.

- [ ] **Step 2: Add the city validator to `build.mjs`**

Insert immediately after the `buildContent()` function definition, before the line `const content = buildContent();`:

```js
/* ---- the city map -------------------------------------------------------
   Same contract as the copy above: authored in content/, inlined here, and
   rejected loudly rather than shipped broken. */
const BLOCKS = 8;                    // mirrors src/00_core.js
const KINDS = ['res', 'com', 'park', 'lot', 'shop', 'retail', 'civic', 'apts', 'church', 'auto', 'rail'];
const CARD_TEXT_PX = 135;            // order card: 140 wide at x=3, text inset to x=8, 3px pad

/* Mirrors the address rule in 40_city.js genResidential. The widest number a
   house can carry is hundred + 22 + 7, so this is the true worst case, not a
   sample. */
function worstAddress(city) {
  let worst = '';
  const keep = (s) => { if (s.length > worst.length) worst = s; };
  for (let by = 0; by < BLOCKS; by++) {
    for (let bx = 0; bx < BLOCKS; bx++) {
      const pre = bx < 4 ? 'W ' : 'E ';
      const hundredEW = (bx < 4 ? 4 - bx : bx - 3) * 100;
      keep(`${hundredEW + 29} ${pre}${city.streetsEW[by]}`);
      keep(`${hundredEW + 29} ${pre}${city.streetsEW[by + 1]}`);
      const hundredNS = parseInt(city.streetsEW[by + 1], 10) * 100;
      keep(`${hundredNS + 29} ${city.streetsNS[bx]}`);
      keep(`${hundredNS + 29} ${city.streetsNS[bx + 1]}`);
    }
  }
  return worst;
}

function buildCity() {
  const raw = JSON.parse(readFileSync(join('content', 'hays.json'), 'utf8'));
  const out = {};
  for (const [k, v] of Object.entries(raw)) if (!k.startsWith('_')) out[k] = v;

  for (const key of ['streetsNS', 'streetsEW']) {
    const a = out[key];
    if (!Array.isArray(a) || a.length !== BLOCKS + 1)
      throw new Error(`content/hays.json: "${key}" must be exactly ${BLOCKS + 1} street names, got ${Array.isArray(a) ? a.length : typeof a}`);
    for (const s of a) {
      if (typeof s !== 'string') throw new Error(`content/hays.json: "${key}" must contain only strings`);
      const up = s.toUpperCase();
      if (!FONT_CHARS.test(up)) {
        const bad = [...new Set([...up].filter((ch) => !FONT_CHARS.test(ch)))].join(' ');
        throw new Error(`content/hays.json: street name ${JSON.stringify(s)} uses characters the 5x7 font cannot draw: ${bad}`);
      }
    }
  }

  const z = out.zoning;
  if (!Array.isArray(z) || z.length !== BLOCKS)
    throw new Error(`content/hays.json: "zoning" must be ${BLOCKS} rows, got ${Array.isArray(z) ? z.length : typeof z}`);
  const shopCells = [];
  z.forEach((row, by) => {
    if (!Array.isArray(row) || row.length !== BLOCKS)
      throw new Error(`content/hays.json: zoning row ${by} must be ${BLOCKS} entries, got ${Array.isArray(row) ? row.length : typeof row}`);
    row.forEach((kind, bx) => {
      if (!KINDS.includes(kind))
        throw new Error(`content/hays.json: zoning[${by}][${bx}] is "${kind}", which is not one of: ${KINDS.join(' ')}`);
      if (kind === 'shop') shopCells.push({ bx, by });
    });
  });
  if (shopCells.length !== 1)
    throw new Error(`content/hays.json: zoning must contain exactly one "shop" cell, found ${shopCells.length}`);
  if (!out.shop || out.shop.bx !== shopCells[0].bx || out.shop.by !== shopCells[0].by)
    throw new Error(`content/hays.json: "shop" is ${JSON.stringify(out.shop)} but the shop cell in zoning is at ${JSON.stringify(shopCells[0])}`);

  /* The restock line "<addr> WAITING" overflows the order card before the bare
     address does, so guard the line, not the address. Three text-overflow bugs
     have shipped in this card already. */
  const widest = worstAddress(out).toUpperCase();
  const line = widest + ' WAITING';
  const px = line.length * 6 - 1;
  if (px > CARD_TEXT_PX)
    throw new Error(
      `content/hays.json: the longest address the generator can make is "${widest}", so the restock line\n` +
      `  "${line}" is ${px}px wide, but the order card fits ${CARD_TEXT_PX}px.\n` +
      `  Shorten a street name by ${Math.ceil((px - CARD_TEXT_PX) / 6)} character(s).`);

  return out;
}
```

**Interfaces:**

- Produces: `house.addr` as `"<number> <W|E >?<STREET>"`, e.g. `333 W 8TH ST` or `1006 MAIN ST`. `house.street` keeps the prefix; `house.num` is the integer.

The real convention: a house fronting a **numbered** street takes a `W`/`E` prefix and a hundred-block from its distance to Main. A house fronting a **named** street takes its hundred-block from the numbered street on the block's south edge — which is why Hays City Hall is 1507 Main and the Ellis County Courthouse is 1204 Fort.
