## I. Easy

### A. Shift

- Starting Timer : 3:00 Minutes

- Starting Tip : 20.00 

- Depreciation Rate  : 1.00 / 3 Seconds

### B. Bonus Structure

#### 1. Extended Play

- All 3 Items Complete: +1:30 Time Bonus

  - Delivery Shift : all 3 bags from one load delivered

  - Kitchen Shift : 3 tickets served

- Maximum Extensions Per Shift: 5

Time comes only from the starting timer and these extensions, in both shifts. The game
today adds +0:09 per delivery and +0:03 per perfect one; those go.

#### 2. Points Bonus

- Delivery Shift (as the game plays today)

  - Perfect Delivery (bag lands on the doorstep) : +5.00

  - Combo : x1.00 rising 0.25 per delivery, to x3.00. Reset by a missed throw, a crash, a pedestrian or a police ticket

- Kitchen Shift

  - Clean Ticket (served with no wrong clicks) : +5.00

  - Combo : x1.00 rising 0.25 per ticket served, to x3.00. Reset by a walkout

The combo multiplies everything a delivery or ticket pays, bonus included.

### C. Penalties

- Speeding Ticket : 5.00

- Hitting Pedestrian : 2.00

- Hitting Train : 5.00

### E. Kitchen Shift

See GDD §IV.F for how these are used.

- Starting Tip per Item : 5.00

- Depreciation Rate : 1.00 / 8 Seconds

A ticket's tip is also its patience, so these two set how long a customer waits: 40s for
a 1-item ticket, 120s for 3 items, 200s for 5. A 3-item ticket served 30s after it
arrives pays $11.25, level with an Easy delivery. Paper estimates, set 2026-09-26; tune
them by playtest.
